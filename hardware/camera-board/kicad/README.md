# KiCad 9 プロジェクト（カメラ基板）

`OG19_PC-3_camera.kicad_pro` をダブルクリックすると、回路図と基板が開きます。
`../eagle/` の Eagle データを KiCad 9.0 で読み込んで作ったものです。

## Eagle 版との照合（2026-11-12）
| 項目 | 結果 |
|---|---|
| 接続（ネット16本、全パッド） | Eagle 版・回路図・基板の3つで一致 |
| 配線 / ビア / 外形 | 201本 / 52個 / 39.3 × 17.2 mm で Eagle 版と同じ |
| DRC（クリアランス・未配線） | エラー 0（GND ベタ充填済み） |

### 読み込み後に直したところ
- 基板のネット名を回路図のネット名にそろえた（Eagle の `N$1` などを KiCad 形式の名前に）。
- 標準のクリアランスを 0.2 → **0.15 mm** に変更（元の設計の最小間隔 6 mil = 0.1524 mm に合わせた）。
- 回路図の部品と基板のフットプリントの対応を修正（`R0603` → `R0603_348`、`CHIPLED_0603` → `CHIPLED_0603_259`）。
- 状態表示 LED の部品番号は、KiCad の決まりで `GND` → **`GND0`** に変わっています（JLCPCB 用の BOM/CPL では `GND` のまま）。

### 残っている警告（問題なし）
- HDMI（CN1）の 17番（DDC/CEC GND）と 19番（HPD）が未接続：元の設計どおり。
- `UNK_HOLE_0/1`：基板の取り付け穴（非メッキ穴）。回路図に部品がないため「余計なフットプリント」と表示される。
- シルク文字の大きさ・太さ：Eagle の文字設定をそのまま引き継いだもの。
- 電源ピンが駆動されていない（ERC）：回路図に PWR_FLAG がないため。動作には関係なし。

## ガーバーの出力
「ファイル → 製造用ファイル出力 → ガーバー」と「ドリルファイル」で出力し、1つの zip にまとめます。
基板を直さない場合は、`../gerber/` の zip をそのまま使ってください。
