# KiCad 9 プロジェクト（メイン基板）

`OG19AWv2_main.kicad_pro` をダブルクリックすると、回路図と基板が開きます。
`../eagle/` の Eagle データを KiCad 9.0 で読み込んで作ったものです。
KiCad 10 以降でも開けますが、保存するとファイルが新しい形式になり、KiCad 9 では開けなくなります。

## Eagle 版との照合（2026-11-12）
| 項目 | 結果 |
|---|---|
| 接続（ネット50本、全パッド） | Eagle 版・回路図・基板の3つで一致 |
| 配線 / ビア / 外形 | 632本 / 125個 / 79 × 42 mm で Eagle 版と同じ |
| ベタ | AGND・DGND を表裏に（計4枚）、充填済み |
| DRC（クリアランス・未配線） | エラー 0 |

### 読み込み後に直したところ
- 基板のネット名を回路図のネット名にそろえた（Eagle の `N$1` などを KiCad 形式の名前に）。
- 標準のクリアランスを 0.2 → **0.15 mm** に変更（元の設計の最小間隔 6 mil = 0.1524 mm に合わせた）。
- 回路図の部品と基板のフットプリントの対応を修正（`R0603` → `R0603_334`、`C0603` → `C0603_334`）。
- 基板のフットプリントの「値」を回路図にそろえた（ボタン3個・コネクタ2個）。

### 部品番号の違い
KiCad の決まり（部品番号は「文字＋数字」）のため、いくつかの部品番号に `0` が付いています。JLCPCB 用の BOM/CPL や説明書は Eagle 版の名前のままです。
| Eagle / BOM・CPL | KiCad |
|---|---|
| PCM5102A | PCM5102A0 |
| SW_MAIN / SW_SUB / SW_UP / SW_DOWN | SW_MAIN0 / SW_SUB0 / SW_UP0 / SW_DOWN0 |
| SPK | SPK0 |
| 5V | UNK5V0 |

### 残っている警告（問題なし）
- 使っていないピンが未接続：Raspberry Pi の40ピンのうち使っていない GPIO と GND、HDMI（CN3）の 11・17・19番。元の設計どおり。
- `UNK_HOLE_0/1`：取り付け穴（非メッキ穴）。回路図に部品がないため「余計なフットプリント」と表示される。
- 40ピンの25番（AGND）の表面側サーマルのスポークが1本：裏面と配線でつながっているので問題なし。
- VR1 まわりの 0.9 mm の短い配線の切れ端：元の設計にあったもの。
- シルクの重なり・文字の大きさ：Eagle のシルク設定をそのまま引き継いだもの（JLCPCB は自動で調整する）。

## DRC の結果（2026-11-25、シルクの文字を大きくしたとき）
KiCad 9.0.8 で、すべての重要度（エラーと警告）と回路図との照合を有効にして実行しました。
| 項目 | 結果 |
|---|---|
| エラー | 1件（上の「40ピンの25番のサーマル」。前からあるもの） |
| 警告 | 83件（変更前 128件。新しく増えたものはなし） |
| 未配線 | 0 |
| 回路図との照合 | 26件（ネット名の表記の違いと取り付け穴。変更前と同じ） |

このとき、次の2つを直しました。
- 表面のシルクの「github.com/photonglass/photonglass / CERN-OHL-S v2」と「PHOTON GLASS / 2026 / PB-4」を、文字の高さ 1.0 mm・線の太さ 0.16 mm にした（JLCPCB の最小値は高さ 1.0 mm・線の太さ 0.153 mm）。Eagle のデータも同じく直してある。
- Eagle の線幅 0 の補助線（基板全体を区切る縦横の線、8本）が、KiCad では表面のシルク（線幅 0.1 mm）として読み込まれていたので、印刷されない User.Drawings レイヤーに移した。Eagle からガーバーを作るスクリプトはこの線を出力しないので、`../gerber/` の zip には元から入っていない。KiCad でガーバーを出力したときにだけ、この線が印刷されていた。

## ガーバーの出力
「ファイル → 製造用ファイル出力 → ガーバー」と「ドリルファイル」で出力し、1つの zip にまとめます。
基板を直さない場合は、`../gerber/` の zip をそのまま使ってください。
`../gerber/` の zip は、Eagle のデータからスクリプトで作ったものです（[`../../JLCPCB_ORDERING.md` の「ガーバーについて」](../../JLCPCB_ORDERING.md#ガーバーについて)）。KiCad で出力すると、ベタGNDの広がり方（基板の端や穴からの間隔）とシルクの文字の形が、この zip と少し変わります。
