# Contributing

Contributions to PHOTON GLASS are welcome.
The project's principles and how its name is to be used are set out in [`CHARTER.en.md`](CHARTER.en.md) (the Charter). Please read it before making changes.

## Questions and bug reports

These are accepted through GitHub Issues.
https://github.com/photonglass/photonglass/issues

When you open an issue, choose either the "不具合を報告する / Report a bug" template or the "質問する / Ask a question" template.

## Proposing changes (pull requests)

1. Fork the repository
2. Create a branch for your changes
3. Make your changes
4. Check that it works (for software changes, please test on the actual device as far as possible; if that is difficult, say so in the pull request)
5. Send a pull request

## Updating documents (Japanese and English versions)

The documents come in Japanese and English versions. The English version of a document is the file in the same folder as the Japanese version whose name ends in `.en.md` (for example, `README.en.md` and `docs/SETUP_RASPBERRY_PI.en.md`).
When you update a document, please update its English version at the same time. The issue templates (`.github/ISSUE_TEMPLATE/`) give each item in both Japanese and English, so please update both languages there as well.

## Large changes

If you are thinking of making changes to the fundamentals of the boards, enclosures or program, or modifications that add new functions or purposes, please discuss them in an issue before you start work.

Depending on the outcome of the discussion and the nature of the change, we may ask you to publish it as an independent project in a fork rather than having it merged into this repository. In that case, follow the naming guidelines in [`CHARTER.en.md`](CHARTER.en.md#2-the-name), give it a new name suited to its purpose, and state in the credits that it is based on PHOTON GLASS. You are free to publish a fork as long as you follow the terms of each licence.

Changes that improve PHOTON GLASS itself, such as bug fixes, documentation improvements and substitutions with compatible parts, are welcome as ordinary pull requests.

## Licences and rights

The changes you send will be released under this repository's licences (software: GPL-3.0-only; hardware: CERN-OHL-S v2; documentation, photos, images and sounds: CC BY-SA 4.0). For which licence applies to what, see ["Licences" in the README](README.en.md#licences).
We do not ask you to sign a CLA (Contributor License Agreement).
