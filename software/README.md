# ソフトウェア

OTON GLASS の Raspberry Pi で動かすプログラムです。
カメラボタンを押すと写真を撮り、写っている文字を Google Cloud で読み取って、スピーカーから読み上げます。

## ファイル
| ファイル | 内容 |
|---|---|
| `main_async.py` | 本体プログラム（**非同期版**）。**普段はこちらを使う** |
| `main_seq.py` | 本体プログラム（**逐次版**）。仕組みを学ぶための、流れの読みやすい版 |
| `sound/` | 効果音（起動・シャッター・通信中・読み上げ前後・エラー） |
| `test/hw_test.py` | 組み立て後の動作テスト（LED → ボタン → スピーカー → カメラ） |

## どちらを使えばいい？
**普段使うのは `main_async.py`、仕組みを知りたいときに読むのは `main_seq.py`** です。
2つとも、やっていること（撮影 → 文字の読み取り → 音声の作成 → 読み上げ）は同じです。違うのは「処理の進め方」です。

### `main_seq.py`（逐次版）：まず読むならこちら
料理にたとえると、**「お湯が沸くまでコンロの前でじっと待ってから、次の作業をする」** 進め方です。

- 撮影 → 読み取り → 音声作成 → 読み上げを、**上から順に1つずつ**、前の処理が終わるのを待ってから進めます。
- プログラムの流れが上から下へまっすぐなので、**どの順番で何が起きるかを追いやすい**です。
- その代わり、処理の途中ではボタンに反応しません。読み上げが始まったら、最後まで聞くしかありません。

### `main_async.py`（非同期版）：普段使うならこちら
料理にたとえると、**「お湯を沸かしている間に野菜を切り、呼ばれたらすぐ手を止める」** 進め方です。

- 通信の返事を待っている間も、**効果音を鳴らしたり、ボタンを見張ったりを同時に**進めます（Python の `asyncio` という仕組みを使っています）。
- そのため、使う人にとって次のような便利さがあります。
  - 読み上げの途中で**カメラボタン**を押すと、今の読み上げをやめて**すぐ撮り直せる**
  - 読み上げの途中で**サブボタン**を押すと、**読み上げを止められる**
  - 通信中は効果音が流れ続けるので、「いま処理している」ことが耳でわかる
- 「同時に進める」ための仕組みが入っている分、プログラムの流れは少し追いにくくなります。

### 違いのまとめ
| | `main_seq.py`（逐次版） | `main_async.py`（非同期版） |
|---|---|---|
| 向いている使い方 | 仕組みを学ぶ・改造の練習 | 普段使い |
| 処理の進め方 | 1つずつ順番に | 待ち時間の間に、ほかのことも同時に |
| 処理中のボタン | 反応しない | 撮り直し・中止ができる |
| 通信中の効果音 | 1回流れる | 通信が終わるまでくり返し流れる |
| 起動音が鳴っている5秒間 | 操作できない | ボタンを押せばすぐ止まって使える |
| 通信に使うライブラリ | `requests` | `httpx` |

おすすめの読み方：まず `main_seq.py` で全体の流れをつかみ、そのあと `main_async.py` で「同じ流れを同時に進めるにはどう書くか」を見比べると、理解しやすいです。

## 動かし方
1. Google Cloud で API キーを作り、**Cloud Vision API** と **Cloud Text-to-Speech API** を有効にする。
   - キーには「使える API の制限」（この2つだけ）を付けておくと安全です。
2. 使うプログラム（`main_async.py` か `main_seq.py`）を開き、先頭の `api_key = "YOUR API KEY"` を自分のキーに書き換える。
   - **キーを書き込んだファイルは、GitHub などで公開しないでください。** 他人に使われて料金が請求されることがあります。
3. 必要なライブラリを入れる。
   ```
   sudo apt install -y python3-gpiozero python3-picamera2 python3-httpx python3-requests
   ```
4. この `software` フォルダに移動してから実行する（効果音の場所を、今いるフォルダから数えているため）。
   ```
   cd software
   python3 main_async.py
   ```

## LED の色の意味
| 色 | 状態 |
|---|---|
| 緑 | 待機中（ボタンを押せる） |
| 黄 | 通信中 |
| 青 | 読み上げ中 |
| 赤 | エラー（効果音でどのエラーかを知らせる：カメラ／通信／文字が見つからない） |

2026年版の基板では RGB LED の部品を替えたため、GPIO9 = 赤、GPIO11 = 緑、GPIO10 = 青 です（元の基板とは違います）。
